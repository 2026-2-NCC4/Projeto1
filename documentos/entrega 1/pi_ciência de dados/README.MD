## 📖 Descrição da Entrega

Esta entrega tem como objetivo apresentar o processo de **exploração, seleção, limpeza, transformação e organização** da base de dados financeiros utilizada no projeto.

A base corresponde a uma **simulação de Monte Carlo de uma empresa de concessão**, contendo diferentes cenários financeiros projetados ao longo de 12 anos.

As atividades realizadas envolvem:

- Exploração e compreensão da estrutura dos dados;
- Identificação da fonte e coleta dos dados;
- Seleção das informações relevantes para o projeto;
- Limpeza e uniformização dos dados;
- Tratamento dos valores financeiros;
- Transformação da base para um formato analítico;
- Criação de indicadores financeiros derivados;
- Formatação da base final;
- Documentação das etapas realizadas.

## 📊 Resultado da Preparação

Ao final desta etapa, foi obtida uma base analítica com:

- **14.400 registros**
- **29 colunas**
- **24 contas financeiras selecionadas**

- **12 anos**
- **1.200 cenários**

Os indicadores derivados desenvolvidos nesta etapa foram:

- **Margem EBITDA**
- **Margem Líquida**

Essa base estruturada será utilizada como ponto de partida para as próximas etapas do projeto, incluindo as análises financeiras, desenvolvimento de novos indicadores e construção do dashboard analítico.
